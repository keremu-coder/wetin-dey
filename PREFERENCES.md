# AI preferences for this project

## Always
- Give COMPLETE file contents, never partial edits
- Never say "Ctrl+F search for X"
- Never say "add this below line N"
- If a file needs changing, paste the whole file fresh
- I don't know how to edit code manually
- One file per section, with the full file path as a header
- Exact commands I can copy-paste
- Tell me the terminal command to run

## When I say "which file?"
- Give the exact Notepad command
- Give what to delete
- Give what to paste
- Give what to save

## Never
- Skip steps assuming I know
- Give a partial fix
- Ask me to find a line in a file
- Say "make a small change"
- Give a diff or patch

## Code style
- Full file, no fragments
- Use TypeScript, no `any` unless unavoidable
- Supabase client side vs server side matter
- Always handle errors gracefully
